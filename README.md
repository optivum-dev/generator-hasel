# 🔐 Generator haseł

Proste i bezpieczne narzędzie do generowania losowych, silnych haseł zgodnie z wybranymi kryteriami.

## ✨ Funkcjonalności
- Ustawianie długości hasła.
- Wybór zestawu znaków: małe litery, wielkie litery, cyfry, znaki specjalne.
- *(Opcjonalnie)* Wykluczanie podobnych znaków (np. `0/O`, `l/1`) lub powtórzeń.
- *(Opcjonalnie)* Podgląd siły hasła oraz szybkie kopiowanie do schowka.
